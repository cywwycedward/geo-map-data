# 采用 monorepo 与分层项目目录和 Agent 配置

Geo Map Data 采用单一 Git monorepo，根目录 `.git/` 是唯一 Git 元数据目录；项目按 `apps/`、`services/` 和 `docs/` 分组，当前只建立 `apps/web/` 与服务预留目录，不预设具体服务名称。根目录指令文件维护全仓库不变量，子项目指令文件维护技术栈和局部命令；项目级 Codex/Claude Code 配置只共享无凭据、可复现的团队内容，本机路径、令牌和个人实验配置保持本地。专属开发从目标子项目目录启动 Agent，跨项目工作从仓库根目录启动；CI 在首个子项目具备可验证命令前暂不启用。若未来出现严格仓库级权限、独立发布/版本策略或独立历史的需求，再重新评估拆分仓库。
