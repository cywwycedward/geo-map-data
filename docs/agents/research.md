# Research Notes

Research findings live in `docs/research/` as one Markdown file per topic.

## Conventions

- Use a concise, lowercase, hyphenated filename: `docs/research/<topic>.md`.
- Capture the question or scope near the top of the file.
- Cite the primary source for each material claim, preferably official documentation, specifications, source code, or first-party APIs.
- Separate verified findings from assumptions, open questions, and recommendations.
- Update an existing note when researching the same topic; create a new note when the scope is meaningfully different.

## When a skill completes research

Save the findings to `docs/research/<topic>.md`, creating `docs/research/` when needed. Report the saved path in the final response.
